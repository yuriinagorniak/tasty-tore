TastyTore
TastyTore is a web application that helps users with personalized meal planning, recipe discovery, and inventory management. Users can browse recipes, create weekly menus, manage shopping lists, and track food supplies—all while enjoying an intuitive and responsive user interface.

Features
Recipe Discovery: Browse and search for recipes.
Personalized Meal Plans: Create weekly meal plans based on dietary preferences.
Inventory Management: Track food items in your pantry, with the ability to add and remove products.
Shopping List: Add ingredients from recipes to your shopping list for easy grocery shopping.
Authentication: Firebase authentication for secure user sign-in and data storage.

Technologies Used
Frontend: React, React Router, Tailwind CSS
Backend (Firebase): Firebase Authentication, Firestore Database
APIs: Edamam Recipe API (for recipe data)
